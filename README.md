# Traffic Crash Analysis And Safety Intelligence Platform
Traffic Crash Data Analysis using SQL, Python and Streamlit

🚨 Problem Statement
Traffic accidents are one of the major causes of injuries and fatalities.Understanding the causes and patterns behind traffic accidents is esssential for improving road safety.This project aims to analyse traffic crash data to identify accident trends,accident-prone zones, analyze factors contributing to high-severity crashes using data analysis.

🎯 Objective
Analyze crash data using advanced SQL techniques
Identify patterns, trends, and risk factors
Generate business insights from structured data

📂 
Dataset Information
Dataset contains Chicago's traffic crash records.
It is pre-cleaned and standardized
Includes:
Crash time and date
Location details
Road and environmental conditions
Injury severity data
Contributing causes
